# homebrew-cablescope

[CableScope](https://github.com/tzzs/cablescope) 的 Homebrew tap。

```bash
brew tap tzzs/cablescope
brew install --cask cablescope
```

`Casks/cablescope.rb` 由 [cablescope 仓库的 release 工作流](https://github.com/tzzs/cablescope/blob/main/.github/workflows/release.yml) 在每次发版时自动更新 `version` 与 `sha256`，无需手动维护。
